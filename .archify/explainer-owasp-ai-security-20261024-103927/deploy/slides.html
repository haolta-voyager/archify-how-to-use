04 · Phòng thủ

Đừng hỏi chặn thế nào. Hãy hỏi bị lừa thì nó làm được gì.

Lớp mềm

  • Dặn trong CLAUDE.md
  • Rule deny trong file cấu hình
  • Hỏi xác nhận từng lệnh

Ranh giới thật

  • Sandbox ở mức OS hoặc container
  • Không có secret đáng lấy trong tầm với
  • Token ngắn hạn, phạm vi hẹp
04 · Phòng thủ · Quyền

Cấu hình quyền cho agent như IAM cho một service

1 · Deny đọc .env, ~/.ssh, ~/.aws
2 · Deny sửa cấu hình của agent
3 · Allowlist test, lint, build
4 · Hỏi ở mạng, push, install
5 · Hook chặn lệnh nguy hiểm
// .claude/settings.json
{ "permissions": {
  "deny": ["Read(./.env*)",
           "Read(~/.aws/**)",
           "Read(~/.ssh/**)",
           "Edit(./.claude/**)"],
  "allow": ["Bash(npm test:*)"],
  "ask": ["Bash(git push:*)",
          "Bash(npm install:*)",
          "WebFetch"]
}}

Rule deny chỉ là lớp mềm. Ranh giới thật nằm ở OS hoặc container.

04 · Phòng thủ · Sandbox

Đặt ranh giới ở OS, không ở prompt

1

Sandbox có sẵn của công cụ

Claude Code /sandbox, Codex CLI --sandbox workspace-write.

2

Devcontainer hoặc VM

Không mount ~/.ssh, ~/.aws, Docker socket.

3

Chặn mạng ra ngoài

Chỉ cho phép registry và domain cần thiết.

Muốn chạy YOLO? Chỉ trong container không credential, không mạng.

04 · Phòng thủ · Secret

Để agent không có gì đáng lấy

  • Không để secret plain text trong repo
  • Secret manager inject lúc chạy: op run, Doppler, Vault
  • Token ngắn hạn, phạm vi hẹp; publish npm bằng trusted publishing
  • Không đăng nhập sẵn tài khoản admin hay production trong shell của agent
04 · Phòng thủ · MCP

Đếm vòng trifecta trước khi bật MCP

Nội dung ngoài
MCP server
Secret / dữ liệu
Kênh ra
  • Ghim phiên bản server
  • Mỗi server một token, quyền tối thiểu
  • Không bật cùng lúc MCP đọc nội dung ngoài và MCP gửi ra ngoài

Mỗi MCP server là một vòng mới trong lethal trifecta.
