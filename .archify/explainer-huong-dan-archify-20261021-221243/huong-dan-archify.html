Answer

Bạn chỉ cần mô tả bằng lời cho Claude: skill Archify tự soạn file nguồn, tự kiểm tra rồi xuất một file HTML tương tác vào thư mục .archify/.

  1. Skill đã cài global cho Claude Code tại C:\Users\PC\.claude\skills\archify.1
  2. Node phải từ v22.20 trở lên; máy đang dùng v22.23.4 nên đã chạy được.
  3. Có 10 loại sơ đồ và một dạng trang giải thích (explainer).2
  4. Muốn tự chạy thì dùng CLI archify.mjs với các lệnh guide, preview, finalize.

Applies toArchify v3.2.0Claude Code trên Windows 11Node v22.23.4

Từ yêu cầu tới file HTML diễn ra thế nào?

Diagram structure
  • Mô tả yêu cầu request
  • Chọn loại sơ đồ pick
  • Viết candidate write
  • Chạy finalize finalize
  • Đạt kiểm tra? ok
  • Sửa candidate fix
  • Mở file HTML open
  • finalize → ok
  • fix → finalize · chạy lại
  • ok → fix · không
  • ok → open · có
  • pick → write
  • request → pick
  • write → finalize
  1. Mô tả yêu cầu ↗

    Nói rõ chủ đề và loại sơ đồ, ví dụ “vẽ sơ đồ kiến trúc repo này”.

  2. Chọn loại sơ đồ ↗

    Claude chọn 1 trong 10 loại; nếu mơ hồ thì dùng lệnh guide.

  3. Viết candidate ↗

    Claude viết candidate.json trong thư mục .archify/<loại>-<tên>-<thời gian>/.

  4. Chạy finalize ↗

    Lệnh này validate, render, kiểm tra HTML trong trình duyệt thật.

  5. Sửa candidate ↗

    Nếu một bước kiểm tra lỗi, Claude sửa đúng chỗ rồi chạy lại.

  6. Mở file HTML ↗

    File HTML tự chứa; mở bằng trình duyệt hoặc gửi cho người khác.

LoạiDùng khiCâu yêu cầu mẫu
architectureThành phần hệ thống và cách chúng nối nhau“Vẽ kiến trúc của repo này”
workflowQuy trình có bước và nhánh“Vẽ quy trình deploy CI/CD”
sequenceChuỗi gọi API theo thứ tự“Vẽ sequence luồng đăng nhập”
dataflowDữ liệu chảy qua pipeline“Vẽ luồng dữ liệu ETL”
lifecycleTrạng thái và chuyển trạng thái“Vẽ vòng đời một đơn hàng”
erdBảng, cột, khóa và quan hệ“Vẽ ERD cho schema database”
classClass, interface và quan hệ kế thừa“Vẽ class diagram module payment”
treeCấu trúc cây: thư mục, module“Vẽ cây thư mục của src”
timelineSự kiện theo thời gian“Vẽ timeline sự cố hôm qua”
waterfallThời gian từng span của một request“Vẽ waterfall cho request checkout”

Lệnh CLI nào hay dùng khi tự chạy?

LệnhTác dụng
doctorKiểm tra cài đặt và các renderer
demo <thư-mục>Tạo một sơ đồ demo
guide "<mô tả>"Gợi ý loại sơ đồ phù hợp
examplesLiệt kê các file ví dụ có sẵn
validate <loại> <file.json>Chỉ kiểm tra file nguồn
preview <loại> <file.json> <out.html>Xem trước trực tiếp, tự cập nhật khi sửa
finalize <loại> <file.json> <out.html> --jsonKiểm tra đầy đủ và xuất bản cuối
compare architecture <cũ.json> <mới.json>So sánh kiến trúc trước và sau

Thêm --quality showcase để kiểm tra chất lượng trình bày chặt hơn, hoặc standard cho sơ đồ dày.

Cấu hình những gì trong file nguồn?

meta.locale
en, zh-CN, zh-TW, es, ko, ar; chưa có tiếng Việt cho giao diện
meta.quality_profile
showcase hoặc standard
meta.visual_preset
Chọn phong cách hiển thị
meta.animation
Bỏ trống để giữ chuyển động mặc định
ARCHIFY_UPDATE_CHECK_DISABLED=1
Tắt kiểm tra phiên bản mới

Nội dung chữ trong sơ đồ vẫn viết tiếng Việt được; chỉ nút và nhãn giao diện là theo locale.
